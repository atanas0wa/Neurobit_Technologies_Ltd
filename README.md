# Neurobit Technologies

pnpm workspace on Node.js 24. The company website (Bulgarian and English) is in [`artifacts/website`](artifacts/website/README.md).

## Run the website

```sh
pnpm install
pnpm --filter @workspace/website run dev    # http://localhost:3000
```

On Replit, click **Run** (or start the **artifacts/website: web** workflow) and open the **Preview** tab.

See [`artifacts/website/README.md`](artifacts/website/README.md) for the contact form setup, content editing, deployment and the pre-launch checklist. `replit.md` lists the commands for the other packages.
